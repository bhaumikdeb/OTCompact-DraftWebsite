Practitioner FAQs

Home state — the practitioner's primary state of residence, where they hold their license, provided that state is a member of the OTC. Several answers below depend on this definition, so it's called out once here instead of repeated in each one.

Where is my state in the process? Will it introduce or pass the Compact?

Check the Compact Map for current member states. If your state hasn't introduced the Compact yet, that's the first step — see the next question for how to help. Because the legislative process is unpredictable, there's no way to guarantee if or when a bill will be introduced or enacted in a particular state; the map is updated promptly as that changes.

Once a state is a member, it launches applications on its own timeline — the OTC administrators don't set that schedule, the state's own licensing board does.

My state passed the Compact — can I use my license in other Compact states now?

No. Passing the Compact is an important step, but it doesn't automatically approve your license for use elsewhere. You still need to apply for a privilege to practice in each state once that state opens OTC applications — the application link is on the OTC homepage.

What can I do to help support the Compact?

AOTA works with state occupational therapy associations to advocate for the OT Compact in each state. To get involved, contact your state occupational therapy association.

My home state or the state I want to practice in isn't a Compact member — can I still participate?

No. Both your home state and the state(s) you want to practice in need to be OTC members for you to get a privilege to practice. If a state isn't a member, the only way to practice there is through that state's regular licensing process.

I was licensed under older requirements, or was grandfathered in — does that affect me?

No, you can still participate in the Compact. If you've never had a criminal background check, though, you'll need to complete one through your home state licensing board.

When will privileges to practice be available, how do I apply, and what does it cost?

Each member state opens OTC applications on its own timeline — check current status on the Compact Map, or contact the state licensing board directly for updates.

The OTC fee is $75 per privilege to practice, plus each state's own fee (see Before You Apply for the current list). Both fees are paid together at the end of the application process.

Once your home state opens applications and confirms you're eligible, you can apply for your OTC privilege to practice in any state that's accepting applications.

What's the difference between a license and a privilege to practice?

A license is the standard license granted by your home state. A privilege to practice (PtP) is granted by your home state licensing board and lets you practice in other Compact member states — it's equivalent to holding a license in that state.

Do I need CEUs or a jurisprudence exam in every state?

You only need continuing education units (CEUs) for your home state. You do need to complete a jurisprudence exam in each state where you apply for a privilege to practice — check Before You Apply to see which states require one.

Do I need a criminal background check before applying?

Yes. Your home state won't consider you eligible for the OTC until an FBI criminal background check is complete. Some states already run these automatically; others are still implementing the requirement — contact your home state licensing board to find out how to complete yours.

How can I stay updated on the Compact's progress?

Visit the OTC homepage, follow the OTC on LinkedIn, or join the email list.
